Simulación educativa · no es la VM real

Esto es una simulación, no el laboratorio. Reproduce el comportamiento de los scripts y permisos para practicar el flujo, pero no ejecuta un kernel real: UFW, auditd, Docker, SSH y systemd no están presentes. El laboratorio de verdad se instala en una VM de Ubuntu Server 24.04 (ver instalación). Las credenciales son las mismas que documenta el proyecto y la sesión se reinicia al recargar.
